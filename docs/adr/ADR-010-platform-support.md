# ADR-010: Linux is the MVP target

**Status:** Accepted  
**Date:** 2026-08-31  
**Author:** [Name]

## Decision

- Support Linux as the official MVP platform.
- Keep the project scoped to Linux path semantics and Linux developer tooling.
- Do not expand to macOS and Windows in the first release.

## Why

This keeps the project focused and easier to test and maintain for the first working version.

## Consequences

- Clearer scope.
- Simpler implementation.
- Broader platform support is deferred.
